# Session Review: CosyVoice WebGPU & Somatic Mentorship Funnel

**Date:** June 2, 2026

## Overview
This session focused on elevating the Voix Vive pedagogical platform to full production readiness, specifically targeting the high-fidelity "Living Voice" requirement necessary to drive Bertrand's international mentorship monetization funnel. 

We established that **Cloud-based TTS APIs are economically unviable** for a free, high-traffic educational app. The only sovereign, sustainable architecture is executing the voice cloning entirely on the user's device via WebGPU.

## Engineering Accomplishments

1. **CosyVoice WebGPU Implementation:**
   * Rewrote the generic StepAudio abstraction into a dedicated, mathematical ONNX runtime pipeline (`src/workers/cosyVoiceWorker.js`).
   * Configured the JavaScript environment to dynamically load and sequence the multi-stage CosyVoice 3 ONNX models (`llm.onnx`, `flow.onnx`, `hift.onnx`).
   * Integrated the `useCosyVoice.js` hook directly into `TroubadourWidget.jsx`, enabling the "CosyVoice Pro Voice (Beta)" UI flow.

2. **Mathematical Studio Audio Chain:**
   * Built `src/hooks/useStudioAudio.js` to process the raw floating-point audio generated by the GPU.
   * Implemented a mathematical, algorithmically generated ConvolverNode (Reverb) to simulate a warm vocal booth.
   * Chained Biquad EQ Filters (Warmth/Clarity) and Dynamics Compression to ensure the AI instructor sounds like a professional podcast, aligning with the premium brand required for the mentorship funnel.

3. **Somatic Prompter Component Integration:**
   * Saved the `SomaticStudioPrompter.jsx` component to `src/components/`, establishing the frontend framework for Bertrand's mobile-native recording interface. This component coordinates the physical pacing of the pedagogical content creation.

## Technical Blockers & Decisions
* **Model Download Time:** We attempted to download the `CosyVoice2-0.5B` PyTorch models directly to the AMD 395 for a local backend test, but the massive file size (~2GB) caused the process to hang, and we aborted the download. 
* **Focus Shift:** Since the WebGPU ONNX code is successfully pushed to `main`, the local Python backend fallback is no longer strictly necessary for architectural success, though it remains an option for rapid development if internet speeds permit.
* **Mobile Video Architecture Decision:** Based on infrastructure reviews, any future recording pipeline for the Somatic Prompter *must* bypass Vercel serverless functions (due to 4.5MB body limits) and use **Direct S3 Uploads via Pre-signed URLs** to Cloudflare R2.
